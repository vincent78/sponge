# 05. 核心基础库导读

`pkg` 不是一个必须整体初始化的巨型框架，而是一组按需使用的小包。下面按职责分组。

## 服务运行与传输

| 包 | 职责 | 首读文件/概念 |
|---|---|---|
| `pkg/app` | 多 server 启停和信号优雅退出 | `app.go`、`IServer` |
| `pkg/httpsrv` | HTTP/HTTPS server 与多种 TLS 模式 | `http.go`、`tls_*.go` |
| `pkg/gin` | middleware、统一 response、validator、swagger、静态资源/代理 | 各子目录 README 和 `middleware/*.go` |
| `pkg/grpc` | client/server option、拦截器、TLS、metrics、gateway、benchmark | `interceptor`、`client`、`gtls` |
| `pkg/httpcli` | HTTP 客户端封装 | `httpcli.go` |
| `pkg/ws` / `pkg/sse` | WebSocket 与 Server-Sent Events | server/client 与 README |

## 数据、缓存与一致性

| 包 | 职责 |
|---|---|
| `pkg/sgorm` | GORM 初始化、driver、分页/条件查询、读写分离、通用模型 |
| `pkg/mgo` | MongoDB client 与选项 |
| `pkg/cache` | memory/Redis 的通用 cache 接口与实现 |
| `pkg/goredis` | Redis client 初始化 |
| `pkg/dlock` | Redis/etcd 分布式锁 |
| `pkg/conf` | 配置解析、展示、文件变更回调 |
| `pkg/copier` | 结构体转换选项，隔离 API DTO 与 model |

`internal/database` 把这些通用库按项目配置实例化；不要让 handler 自己新建数据库连接。

## 可观测性与可靠性

| 包 | 职责 |
|---|---|
| `pkg/logger` | 基于 zap 的结构化日志和全局实例 |
| `pkg/tracer` | OpenTelemetry/Jaeger 初始化与关闭 |
| `pkg/stat` | 进程 CPU/内存统计及告警 |
| `pkg/prof` | 信号触发的 profile |
| `pkg/gin/middleware/metrics`、`pkg/grpc/metrics` | transport 指标 |
| `pkg/shield` | 限流、熔断等保护能力的底层实现 |
| `pkg/errcode` | HTTP/RPC 错误码与响应映射 |

横切能力通常在 Gin middleware 或 gRPC interceptor 中接入，而不是散落在业务函数。

## 服务治理与外部系统

- `pkg/servicerd`：注册发现抽象及 etcd/consul/nacos 实现。
- `pkg/etcdcli`、`consulcli`、`nacoscli`：各系统客户端初始化。
- `pkg/kafka`、`rabbitmq`、`sasynq`：消息和异步任务。
- `pkg/gocron`：定时任务。
- `pkg/proxykit`：代理相关能力。

## 生成器的“发动机室”

| 包 | 作用 |
|---|---|
| `pkg/sql2code` | 取得 SQL/数据库 schema，驱动 parser |
| `pkg/sql2code/parser` | SQL AST → model/DAO/handler/proto/service 等代码片段 |
| `pkg/replacer` | 文件树复制、占位替换、模板字段替换 |
| `pkg/goast` | 使用 Go AST 做安全的代码级修改 |
| `pkg/gofile` | 文件路径、查找、复制、内容片段工具 |
| `pkg/gobash` | 带 context 的外部命令执行和流式输出 |
| `pkg/jy2struct` | JSON/YAML 到结构体 |
| `pkg/aicli` | 不同 LLM 客户端的统一辅助能力 |

如果生成结果“字段类型错”，先看 parser；“文件缺了/选错变体”看 generator；“占位符没替换”看 replacer；“已有文件合并坏了”看 goast/merge/patch。

## 其他工具包

- `pkg/gocrypto`、`jwt`、`krand`：密码学、token、随机数。
- `pkg/encoding`：JSON 等编码替换/封装。
- `pkg/container/group`：分组容器。
- `pkg/process`：跨平台终止进程。
- `pkg/gotest`：DAO/cache/handler/service 测试辅助。
- `pkg/utils`：host、slice、string 等零散工具；新增能力前要避免继续扩大“万能 utils”。

## 阅读基础库的方式

每个包先读 README，再读公开 API 和 Option，最后读测试。测试往往比实现更清楚地展示：默认值是什么、错误如何表达、资源由谁关闭。只在业务确实需要时深入第三方库实现。
